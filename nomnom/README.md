# NOMNOM

`MiG29SMT.json` is the manifest submitted to [NOMNOM](https://github.com/KopterBuzz/NOMNOM) (the mod registry used by NOMM),
in KopterBuzz/NOMNOM#443. NOMNOM updates it from this repository's GitHub releases (it takes the first asset, the
`MiG-29SMT-Mod_<version>.zip` built by `tools/build_mig29.ps1`). Keep this copy in sync if the listing changes.
